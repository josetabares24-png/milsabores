# Mil Sabores — Brand Brain

Este directorio es la **fuente de verdad de marca y branding** de Mil Sabores.

## Regla de trabajo

Antes de crear, editar o aprobar cualquier pieza visual o de comunicación de Mil Sabores —post, story, reel cover, flyer, menú, anuncio, web, cartel, campaña o colaboración— se debe consultar esta carpeta.

Las decisiones de marca no deben quedar solamente en chats. Cuando una decisión se apruebe, se registra aquí.

## Archivos

- `BRAND-MEMORY.md` — identidad visual y verbal vigente.
- `SOCIAL-CONTENT.md` — reglas para contenido y publicaciones.
- `DECISIONS.md` — historial de decisiones aprobadas, pruebas y descartes.

## Estados usados

- **LOCKED**: aprobado; no cambiar sin decisión explícita.
- **CURRENT**: vigente, pero puede evolucionar.
- **TEST**: hipótesis o prueba.
- **PENDING**: falta definir.
- **REJECTED**: probado o discutido y descartado.

## Principio

La marca debe sentirse reconocible antes de sentirse “diseñada”.

No inventar reglas nuevas por conveniencia de una pieza. Si una excepción funciona y se quiere repetir, primero se convierte en decisión de marca y se documenta.
